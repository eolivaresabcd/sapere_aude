# SISTEMA DE NUMERACIÓN EXTRATERRESTRE

- se cuenta el sistema decimal y el sistema binario
- se intenta experimentar con un sistema ternario o de otro tipo

- los chavales tienen que hacer una redacción en lengua sobre una civilización extraterrestre
- dibujan en lengua a los extraterrestres. qué aspecto tienen?
- deben contar cómo cuentan (manos, pies, dedos, ojos?)
- a partir de eso se inventan símbolos y una base para su sistema. Ej: 6 dedos, sistema heximal.
